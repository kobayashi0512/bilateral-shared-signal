# Figure 1 — editable study framework

The framework shows the patient as the analysis unit, defines within- and cross-patient eye comparisons, states the frozen scoring operation, distinguishes progressively tighter negative controls, and makes the evidence role of each dataset explicit.

It contains six actual source photographs: four DeepDRiD views (L1, L2, R1, R2) in panel A and a PAPILA OD/OS pair in panel E. CFP–OCT remains text-only because the reviewed repository did not state image-reuse terms. Photos are raster source assets; all text, frames, panel cards, routes, and callouts are editable vector elements.
